# Changelog

## 0.1.0 — Initial development foundation
- Native Qt 6 / C++20 Windows desktop application shell.
- Original Kadris Studio SVG identity and dark graphite theme.
- Dockable Media, Inspector, and Timeline panels.
- Local media import and source playback through Qt Multimedia.
- Basic .kadris project save/open.
- Initial timeline visualization.
- Windows GitHub Actions build workflow.

This is an early prototype. A full non-linear editing engine, sequence rendering, advanced editing tools, effects, audio mixing, color grading, subtitles, and export are not included yet.
