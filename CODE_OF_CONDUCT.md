# Community Code of Conduct

Kadris Studio aims to be a welcoming, respectful, and constructive open-source project.

Participants are expected to be respectful, considerate, and open to constructive feedback; focus criticism on ideas and code rather than people; credit contributors; and respect software and media licenses.

Harassment, discrimination, intimidation, and personal attacks are not acceptable. Project maintainers may remove content or participation that violates these expectations.
