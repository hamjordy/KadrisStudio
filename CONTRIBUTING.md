# Contributing

Thank you for considering a contribution.

Before opening a pull request:
- Check the roadmap and open issues.
- Keep changes focused and use descriptive commit messages.
- Follow existing C++ and Qt conventions.
- Do not add a control that appears functional unless it is connected to working behavior.
- Do not bundle third-party codecs, plugins, models, or libraries without documenting their licenses and redistribution terms.
- Never commit user media, project files, credentials, API keys, or build output.

For code changes, describe the Windows build result, reproduction steps, tests added or updated, and any known limitations. Do not mark placeholder UI as completed functionality.
